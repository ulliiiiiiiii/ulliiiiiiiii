Tools for coding agents and LLMs, and small utilities for the machines I run at home. Most come
with tests and CI.

Available for fixed-price projects, remote, in German, English or Russian. Details at
[ullrich-heinl.com](https://ullrich-heinl.com), or write to contact@ullrich-heinl.com.

### Coding agents and LLMs

- [agent-memory](https://github.com/ulliiiiiiiii/agent-memory): long-term fact memory for coding agents, stored in a single SQLite file
- [ai-sandbox-guard](https://github.com/ulliiiiiiiii/ai-sandbox-guard): a deterministic tool-call guard that keeps coding agents off the open internet
- [controller-worker](https://github.com/ulliiiiiiiii/controller-worker): delegate work from one coding agent to another over SSH
- [safe-page-fetch](https://github.com/ulliiiiiiiii/safe-page-fetch): fetch web pages for LLM pipelines without SSRF

### Homelab and Linux

- [cdp-remote-screen](https://github.com/ulliiiiiiiii/cdp-remote-screen): use a browser on another machine from your phone, live over the Chrome DevTools Protocol
- [homelab-toolkit](https://github.com/ulliiiiiiiii/homelab-toolkit): SSH hardening with automatic rollback, IP failover and clipboard sync for two machines
- [homelab-watchdogs](https://github.com/ulliiiiiiiii/homelab-watchdogs): watchdogs for temperature, power cuts, login attacks and a DNS server that stops answering
- [fritzbox-port-watch](https://github.com/ulliiiiiiiii/fritzbox-port-watch): report port forwardings that devices open on a FRITZ!Box through UPnP
- [gtt-watch](https://github.com/ulliiiiiiiii/gtt-watch): watch the memory gnome-shell takes from system RAM on AMD APUs
- [ray-cluster-demos](https://github.com/ulliiiiiiiii/ray-cluster-demos): a virus spreading through a city of a million people and a Mandelbrot zoom, computed on a Ray cluster
- [lancedb-compactor](https://github.com/ulliiiiiiiii/lancedb-compactor): keep LanceDB tables small, compacting only when there is memory for it
- [sqlite-backup](https://github.com/ulliiiiiiiii/sqlite-backup): back up a SQLite database while the app keeps running, checked and rotated
- [git-rewrite-references](https://github.com/ulliiiiiiiii/git-rewrite-references): update commit references in docs and comments after a history rewrite
- [retroarch-playlists](https://github.com/ulliiiiiiiii/retroarch-playlists): RetroArch playlists for PlayStation and Nintendo DS, with .m3u for multi-disc games

### Documents and spreadsheets

- [pdf-to-docx-structured](https://github.com/ulliiiiiiiii/pdf-to-docx-structured): PDF to an editable Word file, with paragraphs, headings, lists and tables
- [docx-inplace-translate](https://github.com/ulliiiiiiiii/docx-inplace-translate): translate Word files without touching the layout
- [docx-cv-builder](https://github.com/ulliiiiiiiii/docx-cv-builder): write native Word files with the Python standard library only
- [sheet-normalizer](https://github.com/ulliiiiiiiii/sheet-normalizer): clean and merge spreadsheets with German and English number and date formats
- [printable-pdf-planner](https://github.com/ulliiiiiiiii/printable-pdf-planner): a 30-page printable planner as PDF, colored to match your own cover artwork

### Cloud and Windows

- [cdk-secure-baseline](https://github.com/ulliiiiiiiii/cdk-secure-baseline): secure-by-default AWS CDK building blocks, checked by cdk-nag
- [mausi](https://github.com/ulliiiiiiiii/mausi): cursor packs, pointer speed and a touchpad switch for Windows 10 and 11 (German interface)

### Websites and mail

- [cf-email-inbox](https://github.com/ulliiiiiiiii/cf-email-inbox): your own mailbox on a Cloudflare domain, kept in a local Maildir, with a web inbox for phone and desktop
- [chunked-video-upload](https://github.com/ulliiiiiiiii/chunked-video-upload): large video uploads in pieces, resumable, checked with SHA-256 and ffprobe
- [cf-pages-linkinbio](https://github.com/ulliiiiiiiii/cf-pages-linkinbio): link-in-bio pages on Cloudflare Pages and KV, one project for any number of pages
- [bilingual-static-site](https://github.com/ulliiiiiiiii/bilingual-static-site): static site generator for two-language websites, with hreflang pairs and a checked build
- [sitemap-redirects](https://github.com/ulliiiiiiiii/sitemap-redirects): 301 redirects for a website move, from the old sitemap to the new site
- [dmarc-digest](https://github.com/ulliiiiiiiii/dmarc-digest): one table from a folder of DMARC reports: which senders pass and which fail
